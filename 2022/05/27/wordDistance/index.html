数组 - 单词距离

1. 题目描述

        有个内含单词的超大文本文件，给定任意两个不同的单词，找出在这个文件中这两个单词的最短距离(相隔单词数)。如果寻找过程在这个文件中会重复多次，而每次寻找的单词不同，你能对此优化吗?

示例：

输入：words = [“I”,”am”,”a”,”student”,”from”,”a”,”university”,”in”,”a”,”city”]

​ word1 = “a”

​ word2 = “student”

输出：1

解释：第一次出现的角标为2的”a”与”student”距离最近，距离为 1。

提示：

  1. words.length <= 100000

2. 解题思路

2.1 思路一

        暴力遍历，首先遍历给定的单词列表，查找并记录第一个单词和第二个单词在单词列表中出现的位置。然后计算第一个单词出现的位置和第二个单词出现的每一次的位置进行计算距离。每次计算后和当前结果进行对比，保留最小值。

2.2 思路二

        初始化第一个单词和第二个单词出现的位置为-1，证明目前该单词还没有出现在单词列表中。遍历单词列表，每当遇到和第一个单词或者第二个单词相等的单词，就更新该单词出现的下标。如果两个单词出现的下标大于等于0，则代表两个单词都在单词列表中出现过，此时计算两个单词的间隔距离，并更新当前最小距离。

复杂度：

  • 时间复杂度： O(n) 。其中 n 是数组 words 的长度。需要遍历数组一次计算 word1 和 word2 的最短距离，每次更新下标和更新最短距离的时间都是 O(1)。这里将字符串的长度视为常数。
  • 空间复杂度： O(1) 。

3. 算法流程

3.1 思路一流程

  1. 两个单词的最长距离不会超过单词列表长度，所以初始化结果时可以设置成单词列表长度
  2. 初始化保存第一个单词出现的下标的列表，初始化保存第二个单词出现的下标的列表
  3. 遍历单词列表，如果当前单词和第一个单词相等，则将下标保存到第一个单词的下标列表中
  4. 如果当前单词和第二个单词相等，则将下标保存到第二个单词的下标列表中
  5. 嵌套遍历两个单词的下标列表，两两计算出现位置的距离，每次计算后和当前结果进行对比，保留最小值
  6. 返回最终结果

3.2 思路二流程

  1. 两个单词的最长距离不会超过单词列表长度，所以初始化结果时可以设置成单词列表长度
  2. 初始化第一个单词和第二个单词出现的位置 index1 = -1，index2 = -1
  3. 遍历单词列表，如果有和第一个单词或者第二个单词相等的，则更新当前单词出现位置
  4. 如果两个单词出现的下标大于等于0，此时计算两个单词的间隔距离，并更新当前最小距离
  5. 返回最终结果。
