验证IP地址

1. 题目描述

        给定一个字符串queryIP。如果是有效的 IPv4 地址，返回 “IPv4” ；如果是有效的 IPv6 地址，返回 “IPv6” ；如果不是上述类型的 IP 地址，返回 “Neither” 。

有效的IPv4地址 是 “x1.x2.x3.x4” 形式的IP地址。 其中 0 <= xi<= 255 且 xi 不能包含 前导零。

例如:“192.168.1.1”、 “192.168.1.0” 为有效IPv4地址， “192.168.01.1” 为无效IPv4地址; “192.168.1.00” 、 “192.168@1.1” 为无效IPv4地址。

一个有效的IPv6地址是一个格式为“x1:x2:x3:x4:x5:x6:x7:x8” 的IP地址，其中: 1 <= xi.length <= 4, xi是一个 十六进制字符串 ，可以包含数字、小写英文字母( ‘a’ 到 ‘f’ )和大写英文字母( ‘A’ 到 ‘F’ )。,在xi中允许前导零。

例如 “2001:0db8:85a3:0000:0000:8a2e:0370:7334” 和 “2001:db8:85a3:0:0:8A2E:0370:7334” 是有效的 IPv6 地址，而 “2001:0db8:85a3::8A2E:037j:7334” 和 “02001:0db8:85a3:0000:0000:8a2e:0370:7334” 是无效的 IPv6 地址。

示例一：

输入：queryIP = “172.16.254.1”

输出：”IPv4”

解释：有效的 IPv4 地址，返回 “IPv4”

示例二：

输入：queryIP = “2001:0db8:85a3:0:0:8A2E:0370:7334”

输出：”IPv6”

解释：有效的 IPv6 地址，返回 “IPv6”

示例三：

输入：queryIP = “256.256.256.256”

输出：”Neither”

解释：既不是 IPv4 地址，又不是 IPv6 地址

提示：

  1. queryIP 仅由英文字母，数字，字符 ‘.‘ 和 ‘:‘ 组成。

2. 解题思路

2.1 思路一

        我们首先查找给定的字符串 queryIP 中是否包含符号 .。如果包含，那么我们需要判断其是否为 IPv4 地址；如果不包含，我们则判断其是否为 IPv6 地址。

对于IPv4而言，它包含四个由.分割的部分组成，且不能以.开头或者结尾。首先以.将其分割，判断是否是四个部分；然后以此判断每一个部分是否合法。IPv4的每一个部分的长度为1～3之间，全部是由数字组成，且最每部分的数字不包含前导0，范围在[0,255]之间。

对于IPv6而言，它包含八个由:分割的部分组成，且不能以:开头或者结尾。首先以:将其分割，判断是否是八个部分；然后以此判断每一个部分是否合法。IPv6的每一个部分的长度为1～4之间，是由数字[1,9]、字母[a,f]和[A,F]组成。

复杂度：

  • 时间复杂度：O(n) ，其中 n 是字符串 queryIP 的长度。我们只需要遍历字符串常数次。
  • 空间复杂度：O(1) 。

3. 算法流程

3.1 思路一流程

  1. queryIP 长度小于1，直接返回 Neither

  2. 查找 queryIP 中是否包含符号 .。

  3. 如果包含.，则按照IPv4规则处理

    1. 首先判断 queryIP 不能以.开头或者结尾，否则返回 Neither。
    2. 将 queryIP 以 . 分割，分割后的的部分不是 4 个部分，返回 Neither。
    3. 然后遍历切割后的每一部分，长度在[1,3]之间，且不含前导0。否则返回 Neither。
    4. 判断每一部分中的每一个字符是否是在[0,9]之间，否则返回 Neither。
    5. 最后判断当前部分数字不能大于255，否则返回 Neither。
    6. 满足上述所有条件，返回IPv4。

  4. 如果不包含.，则按照IPv6规则处理

    1. 首先判断 queryIP 不能:开头或者结尾，否则返回 Neither。
    2. 将 queryIP 以 : 分割，分割后的的部分不是 8 个部分，返回 Neither。
    3. 然后遍历切割后的每一部分，长度在[1,4]之间，否则返回 Neither。
    4. 判断每一部分中的每一个字符是否是在[0,9]或者[a,f]或者[A,F]之间，否则返回 Neither。
    5. 满足上述所有条件，返回IPv6。
