字符串 - 删除最外层的括号

1. 题目描述

        有效括号字符串为空 ""、"(" + A + ")" 或 A + B ，其中 A 和 B 都是有效的括号字符串，+ 代表字符串的连接。

  • 例如，""，"()"，"(())()" 和 "(()(()))" 都是有效的括号字符串。

如果有效字符串 s 非空，且不存在将其拆分为 s = A + B 的方法，我们称其为原语（primitive），其中 A 和 B 都是非空有效括号字符串。

给出一个非空有效字符串 s，考虑将其进行原语化分解，使得：s = P_1 + P_2 + … + P_k，其中 P_i 是有效括号字符串原语。

对 s 进行原语化分解，删除分解中每个原语字符串的最外层括号，返回 s 。

示例一：

输入：s = “(()())(())”

输出：“()()()”

解释：输入字符串为 “(()())(())”，原语化分解得到 “(()())” + “(())”，
删除每个部分中的最外层括号后得到 “()()” + “()” = “()()()”。

示例二：

输入：s = “(()())(())(()(()))”

输出：“()()()()(())”

解释：输入字符串为 “(()())(())(()(()))”，原语化分解得到 “(()())” + “(())” + “(()(()))”，
删除每个部分中的最外层括号后得到 “()()” + “()” + “()(())” = “()()()()(())”。

示例三：

输入：s = “()()”

输出：“”

解释：输入字符串为 “()()”，原语化分解得到 “()” + “()”，
删除每个部分中的最外层括号后得到 “” + “” = “”。

提示：

  1. 1 <= s.length <= 105
  2. s[i] 为 '(' 或 ')'
  3. s 是一个有效括号字符串

2. 解题思路

2.1 思路一

        遍历 s，并用一个栈来表示括号的深度。遇到(则将字符入栈，遇到) 则将栈顶字符出栈。栈从空到下一次空的过程，则是扫描了一个原语的过程。

一个原语中，首字符和尾字符应该舍去，其他字符需放入结果字符串中。因此，在遇到(并将字符入栈后，如果栈的深度为 1，则不把字符放入结果；在遇到)并将栈顶字符出栈后，如果栈为空，则不把字符放入结果。

其他情况下，需要把字符放入结果。代码对流程进行了部分优化，减少了判断语句。

复杂度：

  • 时间复杂度：O(n) ，其中 n 是输入 s 的长度。仅需遍历 s 一次。
  • 空间复杂度：O(n) ，其中 n 是输入 s 的长度。需要使用栈，长度最大为 O(n)。

2.1 思路二

        遍历字符串s，用一个常量计数器来记录当前左括号(出现的次数，遇到右括号)，需要消耗一个左括号(代表匹配成功一个对括号，当计数器为0时，则代表扫描了一个原语的过程。

一个原语中，首字符和尾字符应该舍去，其他字符需放入结果字符串中。所以当左括号的数量不大于0时，则代表一个原语的开始或者结束，那么当前括号不会添加到返回结果中。其他情况下将字符添加到返回结果中。

复杂度：

  • 时间复杂度：O(n) ，其中 n 是输入 s 的长度。仅需遍历 s 一次。
  • 空间复杂度：O(n) ，其中 n 是输入 s 的长度。需要用数组暂时保存结果，并转换为字符串。部分语言支持字符串的修改，可以做到 O(1) 空间复杂度。

3. 算法流程

3.1 思路一流程

  1. 初始化返回结果res，初始化一个栈用来存储中介过程。
  2. 遍历字符串，取出当前位置的字符。
  3. 如果当前字符是 )，弹出栈顶元素。
  4. 如果当前栈不为空，则将当前元素添加到返回结果中。
  5. 如果当前字符是 (，则将元素入栈。
  6. 遍历完成之后，返回最终结果。

3.1 思路二流程

  1. 初始化返回结果和计数器count=0。
  2. 遍历字符串，取出当前位置的字符。
  3. 如果当前字符是 )，需要消耗一个左括号(来进行匹配，计数器减一。
  4. 如果当前计数器大于0，则将当前字符添加到返回结果中。
  5. 如果当前字符是 (，计数器加一。
  6. 遍历完成之后，返回最终结果。
